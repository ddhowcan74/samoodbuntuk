สมุดพกส่วนตัว V1
ไฟล์ index.html เป็นเว็บแอปแบบไฟล์เดียว เปิดในเบราว์เซอร์ได้
ข้อมูลของแต่ละคนเก็บใน localStorage ของเบราว์เซอร์/อุปกรณ์นั้น ไม่ได้แชร์ข้อมูลระหว่างผู้ใช้

การเผยแพร่:
1) อัปโหลดโฟลเดอร์นี้ไปยัง Netlify Drop
2) หลัง publish จะได้ลิงก์ .netlify.app สำหรับแชร์ให้คนอื่นเปิดใช้งาน
3) การอัปเดตเวอร์ชันใหม่ทำได้ด้วยการลากโฟลเดอร์เวอร์ชันใหม่ไปที่หน้า Deploys ของไซต์เดิม
